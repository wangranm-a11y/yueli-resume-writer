# Good Resume Bullet Examples

Use these examples for style calibration. Preserve the user's facts; do not copy metrics unless they are present in the source.

## Product Manager / AI Product

```markdown
- **用户洞察：** 整理 18 位学生团队、创业团队和小公司用户访谈纪要，提炼出“不知道先做什么 / 模板太多难以决策 / 协作价值出现过晚”3 类核心卡点，并沉淀为引导优化建议。
- **路径优化：** 参与新人引导文案与首屏路径优化，推动将邀请成员从非必经路径调整为关键引导节点，新用户首日创建任务率提升约 11%，团队协作型用户次周留存提升 9%。
- **MVP 落地：** 与开发同学协作完成网页 Demo，支持选择岗位、生成常见问题、连续追问 2-3 轮并返回基础反馈，形成可演示的 AI 面试陪练 MVP。
```

## Operations / Growth

```markdown
- **漏斗复盘：** 围绕广告点击至试听报名链路复盘转化漏斗，识别试听后无人及时跟进的流失问题，并将问题从单点投放转向承接流程优化。
- **流程优化：** 基于转化漏斗复盘梳理试听后 SOP，推动后续跟进流程优化，试听到正式课转化率提升 12%。
```

## Campus / Entrepreneurship

```markdown
- **用户研究：** 与 3 位同学共同发起校园二手书项目，访谈约 70 位学生，提炼教材版本、成色、交易地点等核心决策信息，识别校园教材交易中的信息不对称问题。
- **需求验证：** 上线首月收录 400+ 本教材信息，获得近 200 名用户使用，撮合交易约 80 单，验证校园场景下二手教材信息聚合需求。
```

## Why These Work

- Each bullet starts with a keyword lead.
- Each bullet contains real context and action.
- Each bullet includes evidence, output, metric, or role-fit meaning.
- Each core bullet is expanded enough to read as about 1.5-2 resume lines, not a clipped one-line task label.
- The language translates raw experience into the target role without inventing title or ownership.
