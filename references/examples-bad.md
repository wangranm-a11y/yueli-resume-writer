# Bad Resume Bullet Examples

Use these as things to avoid.

## Missing Keyword Lead

```markdown
- 负责新用户 onboarding 和用户访谈，提出优化建议。
```

Problem: It does not use `- **关键词：**`.

## Too Generic

```markdown
- **产品能力：** 负责很多产品相关工作，提升了综合能力。
```

Problem: It has no task, method, output, metric, or concrete evidence.

## Too Short

```markdown
- **用户访谈：** 访谈 18 位用户并输出优化建议。
```

Problem: It is technically factual but under-expanded. It does not show user type, method, insight, output, or role relevance.

Better:

```markdown
- **用户洞察：** 整理 18 位学生团队、创业团队和小公司用户访谈纪要，提炼出“不知道先做什么 / 模板太多难以决策 / 协作价值出现过晚”3 类核心卡点，并沉淀为引导优化建议。
```

## Unsupported Ownership

```markdown
- **产品负责：** 独立负责 SaaS 产品整体增长策略，使留存显著提升。
```

Problem: It overclaims ownership and uses unsupported vague results.

## Metric Without Source

```markdown
- **增长优化：** 通过数据分析将转化率提升 50%，显著改善业务表现。
```

Problem: Metric is invented unless the source explicitly provides it.

## Paragraph Instead Of Bullets

```markdown
在这段经历中，我主要做了用户研究、需求分析和产品优化，也参与了跨团队协作，整体提升了自己对产品经理岗位的理解。
```

Problem: Experience content must be written as keyword-led bullets.

## Better Rewrite Pattern

```markdown
- **用户洞察：** 围绕新用户首周使用路径整理访谈纪要和行为数据，识别用户在创建任务、邀请成员、使用模板等关键动作上的卡点，为 onboarding 优化提供依据。
```
